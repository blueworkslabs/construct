Help and data sources

Sky Watch opens on a fresh location fix when phone location is allowed for this module in Construct’s Module access. Turn that off under Area to start with the area picker instead. Source, radius and Auto are remembered; coordinates never are.

Radius: 10–100 km. Combined merges matching aircraft using the newest complete position report and retains known identity from active feeds. Amber means stale data. Pinch or double-tap to zoom. The map is north-up; symbols follow ground track, not necessarily the aircraft’s nose direction.

Altitude is barometric, not height above you or terrain. Public feeds have gaps, delays and quotas. No ordinary drone detection, route guarantee or navigation use. Camera/AR is not included.

This module receives permitted aircraft data and optional phone coordinates. It sends only the chosen area to aircraft providers and viewed tile coordinates to OpenStreetMap. Extra aircraft lookups happen only when requested. JSON and position history stay in the current session; raster tiles may be cached by Construct. Leaving closes the session.

Map: © OpenStreetMap contributors. ADSB.lol data: ODbL 1.0. OpenSky: The OpenSky Network; Schäfer et al., “Bringing Up OpenSky”, IPSN 2014. Optional aircraft/airline records: ADSBdb / PlaneBase. No photos or route data.
