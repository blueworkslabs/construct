Help and data sources

Choose a 10, 25, 50 or 100 km radius. Switch between ADSB.lol, OpenSky and Combined. Combined merges matching aircraft using the freshest reported position.

Your chosen area goes to the selected aircraft providers; visible map areas go to OpenStreetMap. Phone location is optional and requested only when you tap Use my location. Map tiles are cached privately on this phone.

Public feeds have gaps, delays and quotas. No ordinary drone detection, route guarantee or navigation use. Camera/AR is not included.

Enable Allow Sky Watch map and data in Module access. Requires Construct alpha23 or later. Rotation keeps the map; leaving closes the workspace. Module code receives no location or aircraft data.

Map: © OpenStreetMap contributors (openstreetmap.org/copyright). ADSB.lol data: ODbL 1.0. OpenSky: The OpenSky Network, opensky-network.org; Schäfer et al., “Bringing Up OpenSky”, IPSN 2014.
