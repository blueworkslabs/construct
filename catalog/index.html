Construct

Small, signed tools for your Android phone.

Install only what you need. Decide what each tool may access. Use local tools offline, and choose when to connect.

Download alpha24 for Android Early-access build for ARM64 phones. Release notes list checksums and known limits.

Get started

  1. Install the app

    Get the APK from GitHub Releases. Already using Construct? Install the new build over it; your tools and their data stay in place.

  2. Refresh the catalog

    Open Browse and tap Refresh catalog. A fresh install already points at this catalog, so there is nothing to type.

  3. Install a tool

    Pick one, read what it asks for, and tap Install. You can grant or refuse each kind of access later in Module access.

Chose a different catalog earlier? Open Settings, tap Use configured registry, then Use catalog to switch to this one.

Tools in this catalog

  • Sky Watch

    New0.1.0

    Aircraft around you, or around any place you choose, on a north-up map. Pick ADSB.lol, OpenSky or both, and a radius from 10 to 100 km. Needs internet and map and data access. Your chosen area goes to the selected aircraft providers (ADSB.lol and/or OpenSky); visible map areas go to OpenStreetMap.

  • Pocket Checklist

    0.3.0

    An offline checklist for up to 30 items. Nothing leaves your phone.

  • Pocket Focus

    0.1.3

    A focus countdown that remembers where you left it, with an optional tone at the end.

  • Pocket Contacts

    0.2.2

    Browse and search your contacts, read only. No editing, no calling, no network.

  • Pocket Camera

    0.1.4

    The native camera with a private album. Gallery copies and on-device photo analysis happen only when you ask.

  • Pocket Measure

    0.1.3

    Estimate a tabletop length from a photo, a printed marker and two taps.

  • Pocket Tones

    0.3.0

    Short, quiet beeps on a button press. Off until you turn it on.

  • Pocket Snake

    0.1.7

    Swipe or tap to play, with your best score saved. Reopening always pauses.

  • Hello Module

    0.3.0

    The smallest possible tool. It exists to prove that install, update and roll back work.

Downloads contain tool code, never your data. Most tools work offline; Sky Watch needs internet for live aircraft and uncached maps. What a tool can do depends on your app version and the access you grant.

Catalog address

This site is the catalog. The app reads one index file here, and every signed package next to it stays unchanged once published. If you run an older build or a self-built host, point Settings at this address and refresh Browse. No reinstall needed.
